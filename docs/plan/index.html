Колонки — варианты. Разговор про вариант идёт веткой под ним: сначала твои слова, потом мой ответ.

Страница в Chrome + маленький сервер на Python (шаг 1)

  • Переделка за минуты: правлю файл, ты обновляешь окно.
  • Ставить нечего: Chrome и Python у Лены уже есть.
  • PDF и картинки Chrome показывает сам.
  • Проводник по дискам делается здесь же: сервер показывает папки.
  • Лог в файле, я читаю его без тебя.
  • Окно — это Chrome без адресной строки, по виду почти программа, но не совсем.
  • Два куска: сервер и страница. Упал сервер — окно пишет «сервер не отвечает».
  • Чужие сайты внутрь не встроить (для проводника это не нужно).

Отдельная программа (pywebview, Tauri, Electron)

  • Своё окно и значок в панели задач, выглядит как настоящая программа.
  • Можно встроить любой сайт и тащить файлы из окна в проводник.
  • Один файл .exe: это удобнее, когда будем продавать.
  • Каждую правку надо пересобирать в .exe и ставить заново.
  • Самосборные .exe антивирусы часто принимают за вирус.
  • Кода больше, особенно в Electron и Tauri.

Ты: выбираю отдельную программу

«Мне не нравится страница в Chrome: Chrome будет по-одному показывать, Яндекс по-другому, человек захочет Opera… Мне нравится отдельная программа. Лежит папка с питоновскими файлами, экзешник просто запускает скрипт. Как в старых добрых играх на дисках: один запускательный файл».

«Смысл защищать код нету: человек возьмёт нейронку, скажет "сделай то же самое на плюсах", и она сделает. Защита — это внешний вид: что мы делаем, какие анимации, как расположены кнопки, какие взаимодействия».

Я: как вижу программу

  • Папка «Элис»: Элис.exe — маленькая запускалка, только стартует скрипт; app\ — наши файлы Python и страница окна, открытые, как ты и хочешь; python\ — свой Python внутри папки, поэтому на ПК ничего ставить не надо.
  • Окно рисует WebView2 — движок Edge. Проверила: он стоит и у тебя, и у Лены (версия 156). Какой браузер у человека, хоть Opera, неважно: окно везде выглядит одинаково.
  • Ничего не переписываем: страница и сервер из шага 1 переезжают внутрь как есть.
  • Запускалка крошечная и собирается встроенным в Windows компилятором (он есть на обоих ПК). Такие антивирусы трогают реже, чем большие самосборные .exe.
  • У Лены уже стоят Python 3.13, pip и Git, есть выход в интернет, так что я могу собирать у неё прямо на месте.

Ты: верю, закрываем

Что делают девочки и почему окно устроено так

Задачи взяты из логов бот-сессий Лены (502) и Ксюши (503) за 18–27.10 и из их ответов мне.

Четыре вида работы

  • Документы по образцу. Лена: АОСР по водопроводу пакетами по 5 актов, всего 65 (п.1, п.3, даты, длины), реестры, комплект по образцам (акт ТО, врезки, гидроиспытание, общий журнал, формы 4/5/6, входной контроль). Ксюша: правка задания на проектирование. Файлы docx.
  • Подбор и сверка. Лена: паспорта труб к узлам и датам актов (паспорт не позже даты акта; было 56 позиций без документов); сверка актов с исполнительным чертежом (длины по уклону, диаметры, узлы, футляры). Сотни страниц PDF-сканов, xlsx, DWG.
  • Пересчёт таблиц. Ксюша: спецификация НК после актов о необходимости (колодцы, муфты, кольца, мастика); таблица колодцев РД_05 по новому профилю, итоги по Ø1000 / 1500 / 2000.
  • Перегон и упаковка. DWG → DXF, .doc → .docx, распаковать сканы, сжать для почты. Сейчас это делает Клод на нашем ПК, минута на файл.

Что мешает сейчас (Telegram)

  • 20 МБ: боту не дошли 5 файлов Лены размером от 28 до 320 МБ.
  • Россыпью: присылают по 7–18 файлов без пояснения, что с ними делать.
  • ×3: правки по одной фразе, один файл Ксюши переделывали трижды.
  • Телефон: результат видно только в телефоне, исходник и копию рядом не открыть.

Каждая часть окна отвечает на одну боль

  • Слева файлы (работает): кинула мышкой, и файл на её ПК. Лимита нет. ← 20 МБ
  • По центру просмотр (PDF, картинки, CSV; дальше DXF, Word, Excel): почти вся их работа — сравнить одно с другим. ← телефон, подбор и сверка
  • Справа лог, потом отчёт Элис: шаги с галочками и вопрос до правки, а не после. ← ×3
  • Внизу кнопки «сделать на этом ПК»: перегон и упаковка делаются скриптом сразу, без Клода. ← перегон
  • Проводник по дискам (твоя мысль): ходить по дискам прямо в окне. Делается тем же сервером.
