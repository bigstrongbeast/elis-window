Путь одного файла

  1. Лена кидает файл в окно, он ложится в «Васильевы Рабочка».
  2. Простое — кнопкой снизу, скрипт за секунды.
  3. Умное — Лена пишет, что нужно. Файл через Яндекс-Диск едет Клоду на твой ПК.
  4. Шаги видны справа сразу. Нужен ответ — вопрос в окне.
  5. Готовое появляется слева, «было / стало» показывает правки.

Как устроена программа
