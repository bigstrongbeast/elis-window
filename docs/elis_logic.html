2 · логика окна

Каждая часть отвечает на одну боль

🦝 Элис● сервер на связишаг 1: без Клода

Файлы работает

Кинула мышкой — файл лёг в папку на её ПК. Лимита нет: проверила на 30 МБ, дошёл целым. ← боль «20 МБ»

Просмотр PDF, картинки, CSV

Почти вся их работа — сравнить одно с другим: акт со сканом паспорта, акт с чертежом, было со стало. Поэтому просмотр в центре и самый большой. ← боль «телефон», подбор и сверка

DXF, Word, Excel — следующими.

Справа: лог → отчёт лог работает

Сейчас здесь лог каждого действия. Я читаю его в файле, тебе ничего пересказывать не нужно. Когда подключим Клода, здесь появится отчёт Элис: шаги с галочками и вопрос, если нужен ответ. ← боль «×3»: вопрос задаётся до правки, а не после

Внизу: кнопки «сделать на этом ПК» дальше

Перегон и упаковка: распаковать, DWG → DXF, склеить PDF, .doc → .docx. Простое делает скрипт сразу на её ПК, без Клода и без интернета. ← «перегон и упаковка»

  • Страница в Chrome плюс маленький сервер на Python на её ПК. Страницу быстро переделать (твоё «браузер пересобирать проще»), а сервер даёт то, чего страница сама не умеет: класть файлы на диск и писать лог. Ставить ничего не надо, Python у Лены уже стоит.
  • Сначала без Клода. Окно полезно уже само по себе: файлы, просмотр, кнопки. Клоду улетает только то, где нужна голова, — подбор, сверка, пересчёт.
  • Лог на каждое действие. Твой вопрос «я перетянул файл, а что произошло?»: ответ записан в лог, и его видно справа в окне.

Проводник прямо в окне (твоя мысль, 10:08): «Windows Explorer, чтобы быстренько побегать по жёсткому диску, не переключаясь между окнами». Делается в этой же странице: тот же сервер показывает папки диска, нажала на файл — он открылся в просмотре. Отдельная программа для этого не нужна, так что вопрос «браузер или программа» пока решается в пользу браузера.
