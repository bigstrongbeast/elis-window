# Окно Элис

Первое приложение для Лены и Ксюши: кинула файл — он на её ПК, рядом просмотр и лог; дальше — Клод.

- `app/` — шаг 1: `server.py` (локальный сервер, лог на каждое действие) и `index.html` (окно).
- `docs/plan/` — лонгрид-план, каждая версия — коммит.
- `docs/elis_logic.html` — что делают девочки и почему окно устроено так.
- `elis_window_preview.html` — первое превью окна.
